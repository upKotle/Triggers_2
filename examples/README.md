# Примеры SVG

Эти семь диаграмм созданы для демонстрации и регрессионных тестов. Это
синтетические SVG со структурой WaveDrom: именованные строки `wavelane_*`,
фрагменты `<use>` по 20 единиц и пронумерованная шкала тактов.
Исходные скачанные изображения в репозиторий не включены.

Входные последовательности и начальные состояния соответствуют семи примерам,
проверенным при адаптации программы. Ожидаемые результаты старых алгоритмов
зафиксированы отдельно в `test_triggers.py`.

| Файл | Тип | Q | #Q |
| --- | --- | --- | --- |
| `rs_nor.svg` | Асинхронный RS, ИЛИ-НЕ | `0001100111` | `1100001000` |
| `rs_nand.svg` | Асинхронный RS, И-НЕ | `1001011101` | `0111101111` |
| `rs_sync.svg` | Одноступенчатый RS | `00011XX111` | `11111XX000` |
| `rs_two_stage.svg` | Двухступенчатый RS | `0111111111` | `1000000000` |
| `jk_two_stage.svg` | Двухступенчатый JK | `0111100001` | `1000011110` |
| `d_two_stage.svg` | Двухступенчатый D | `0000011110` | `1111100001` |
| `d_dynamic.svg` | Динамический D | `11000011110000111100` | `00111100001111000011` |

Для просмотра откройте любой SVG в браузере; для расчёта:

```sh
python3 main.py examples/rs_sync.svg
```
