# Triggers_2 — расчёт триггеров по SVG

Версия [исходного скрипта](https://github.com/TheSawIsTheLaw/triggers), адаптированная 26.10.2026
к скачанным диаграммам WaveDrom. Работает самостоятельно, без установленного
браузера, доступа к сайту и сторонних Python-пакетов. Нужен Python 3.10+.

## Установка

```sh
git clone https://github.com/upKotle/Triggers_2.git
cd Triggers_2
python3 --version
```

Нужен Python 3.10 или новее. Устанавливать пакеты через `pip` не требуется.
В Windows вместо `python3` используйте `python` или `py -3`.

## Запуск

Скачайте картинку задания в формате SVG и передайте путь к файлу:

```sh
python3 main.py путь/к/заданию.svg
```

Программа определит тип триггера по заголовку, покажет прочитанные входы
и напечатает ответы. Для демонстрационного файла:

```sh
python3 main.py examples/rs_sync.svg
```

Последние строки:

```text
Q: 00011XX111
#Q: 11111XX000
```

В ответ на сайте переносите последовательности после `Q:` и `#Q:`,
без пробелов. `X` — латинская заглавная буква, неопределённое состояние.

Можно указать абсолютный путь, в том числе к файлу в «Загрузках».
Путь с пробелами заключайте в кавычки:

```sh
python3 main.py "$HOME/Загрузки/задание (1).svg"
```

Для выбора файла в диалоге:

```sh
python3 main.py
```

Введите путь или нажмите Enter, чтобы увидеть список SVG рядом с `main.py`.
Если своих файлов в папке ещё нет, программа предложит примеры из `examples/`.
Введите номер файла; после расчёта можно выбрать следующий. `0` — выход.

Несколько заданий можно обработать одной командой:

```sh
python3 main.py *.svg
```

Проверить все демонстрационные файлы (в оболочке с поддержкой `*.svg`):

```sh
python3 main.py examples/*.svg
```

Скачанные задания `*.svg` в корне проекта и локальные окружения исключены
из Git через `.gitignore`. Публикуемые синтетические примеры находятся
в [`examples/`](examples/README.md).

Если заголовок изменён или отсутствует, тип можно задать явно:

```sh
python3 main.py задание.svg --type 3
```

| Номер | Тип |
| --- | --- |
| 1 | Асинхронный RS, ИЛИ-НЕ |
| 2 | Асинхронный RS, И-НЕ |
| 3 | Синхронный одноступенчатый RS, И-НЕ |
| 4 | Синхронный двухступенчатый RS, И-НЕ |
| 5 | Синхронный двухступенчатый JK, И-НЕ |
| 6 | Синхронный двухступенчатый D, И-НЕ |
| 7 | Динамический D |

## Как восстановлены сигналы

В старом варианте входы извлекались из `wave: '...'` в URL.
Теперь источником служит содержимое скачанного SVG:

- Строки `wavelane_*` содержат подписи `CLK`, `R`, `S`, `J`, `K`, `D`, `Q`, `#Q`.
- Элементы `<use href="#000">` и `#111` обозначают низкий и высокий уровни.
  `#0m1`/`#1m0` — переходы; `#pclk`/`#nclk` — фронты тактового сигнала.
- Координаты подписей `0, 1, 2, ...` задают интервалы, для которых нужен ответ.
  В приложенных SVG один интервал состоит из двух фрагментов по 20 единиц:
  нельзя просто превратить каждый `<use>` в отдельную цифру.
- Короткие строки Q/#Q задают начальное состояние для типов 4–7.
  Их продолжение не достраивается при чтении, а рассчитывается алгоритмом.

Чтение находится в `src/trigger_reader.py`, запуск и автоматический выбор
алгоритма — в `main.py`. Семь алгоритмов перенесены из исходного проекта;
в их функциях запуска добавлен параметр `diagram`, вычисления сохранены.
Это адаптация формата ввода, а не исправление или независимая проверка
математической модели старого решателя. В частности, старые ограничения
на определение начального состояния остаются в силе.

Поддерживаются SVG WaveDrom со структурой и геометрией проверенных примеров.
Произвольные SVG, изображения PNG и SVG с контурами вместо элементов WaveDrom
не поддерживаются. Теперь на вход нужен локальный файл, а не прежний URL.
При неизвестном графическом элементе, неполных входах или отсутствии нужных
начальных Q/#Q программа сообщает об ошибке.

## Проверка

```sh
python3 -m unittest -v
```

Проверяются входные последовательности всех семи типов, отсутствие
удвоения длины, начальные состояния, соответствие результатов исходным
алгоритмам, обработка ошибочных файлов и работа командной строки.
Тестовые SVG включены в репозиторий и не требуют скачивания заданий с сайта.
GitHub Actions запускает эти проверки на Python 3.10 и 3.14 в Linux,
а также на Python 3.14 в Windows.
